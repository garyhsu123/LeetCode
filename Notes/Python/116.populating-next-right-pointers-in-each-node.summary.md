# LC 116 — Populating Next Right Pointers in Each Node

## Went well

Recognized that level-by-level traversal fits the problem, then improved the initial BFS idea by reusing established `next` pointers.

## Learning

For a perfect tree, process a level only while it has children. Connect each parent's `left` to `right`, then connect `right` to `parent.next.left` only when a neighboring parent exists. This avoids both leaf-level `None` access and the rightmost-parent boundary error.

## Final approach

Walk levels from their leftmost node. Within each level, advance through parents using `parent.next` and establish the two child connections. Time O(N); auxiliary space O(1).

## Next time

When a tree is perfect and links at one level can support the next, look for a constant-space level traversal instead of defaulting to BFS. Check leaf-level and rightmost-node `None` boundaries early.
