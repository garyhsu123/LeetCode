# LC 116 — Populating Next Right Pointers in Each Node

## Went well

I first recognized that the tree should be handled level by level and correctly identified the two connections: `parent.left.next = parent.right` and, when a neighboring parent exists, `parent.right.next = parent.next.left`. I then realized that the current level's completed `next` pointers let me traverse without a queue.

## Mistake

I initially allowed the outer loop to process the leaf level, which made `parent.left` and `parent.right` become `None`. When the second error appeared, I focused on the `parent.next` guard, but that guard only handles the rightmost parent; the actual correction was to stop the outer loop before it reaches the leaf level.

## Final approach

I keep the leftmost node of each non-leaf level and walk across the level using `parent.next`, connecting children within each parent and across neighboring parents. The time complexity is O(N), and the auxiliary space complexity is O(1).

## Takeaway

When I dereference child nodes inside a level loop, I should first verify the loop invariant that every processed node has children. I should check the leaf-level boundary separately from the rightmost-parent boundary where `parent.next` is `None`.
