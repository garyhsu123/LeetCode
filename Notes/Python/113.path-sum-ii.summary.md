Correctly chose recursive traversal immediately and, after one prompt, identified the backtracking pattern: append before visiting children and pop after both return.

## Learning

`tree-leaf-vs-null`: initially treated a missing node as the point to save a path. A valid answer must instead be checked at a leaf (`left` and `right` are both `None`) whose running sum equals `targetSum`. A shared mutable path is safe during DFS, but `stack.copy()` is needed when recording a result so later backtracking does not mutate it.

## Final approach

Run DFS with a shared path list and running sum. Add the current value, save a copy at a valid leaf, recurse into children, then pop to restore state for the sibling branch. Time is `O(N + P)`, where `P` is the total size of returned paths (worst case `O(N^2)`); auxiliary space is `O(H)`, or `O(H + P)` including the result.
